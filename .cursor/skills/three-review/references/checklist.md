# 3D レビュー チェックリスト

前提: 3D を使う目的とターゲット視点で見る。確認できない項目は「評価不能」。

---

## 1. 目的・ターゲット適合

- 目的が一文であるか（世界観 / 360°構造 / 操作デモ）。「かっこいいから」だけになっていないか。
- 2D（静止画・動画）では不足する点が明示されているか。
- 3D がヒーローまたは中核に限定されているか。ページ全体の無駄な 3D 化がないか。
- デフォルト想定（スマホ優先・説明なしで成立）に反する必須操作がないか。

---

## 2. フォールバック・reduced-motion

- WebGL 不可・非対応端末で静止画（または動画）に切り替わるか。
- `prefers-reduced-motion: reduce` でアニメ抑制またはフォールバックするか。
- フォールバック時も見出し・説明・CTA など情報 HTML が残るか。
- ユーザー向けの技術エラー文言を出していないか。
- フォールバック画像・リンクがルール `markup` どおりか。

---

## 3. モデル・ランタイム規約

- 配信形式が glTF / GLB か。Spline embed を使っていないか。
- React なら R3F（`Canvas` 等）。コンポーネント内の imperative Three.js 初期化がないか。
- `@react-three/drei` 等の追加が必要性なしか。依頼なしの依存追加がないか。
- JS がルール `javascript`（`const`/`let`、レキシカル環境、`js-`、インライン禁止）に沿っているか。

---

## 4. パフォーマンス・容量

- 3D ファイル合計 **5MB 以下**（確認不能なら評価不能）。
- テクスチャ最大 **2K**。
- `devicePixelRatio` に上限があるか。
- タブ非表示時に描画ループを止めているか（推奨）。
- 重い OrbitControls や多重エフェクトが目的と衝突していないか。

---

## 5. ローディング・失敗時

- 読み込み中のローディング表示があるか（重いアセットでは必須寄り）。
- 完了時にフラッシュしていないか。
- 失敗時にローディングを終え、フォールバックへ切り替わるか。

---

## 6. アクセシビリティ

- 装飾の canvas に `aria-hidden` 等があり、情報が HTML 側にあるか。
- 主要 CTA・ナビがキーボードで到達できるか。フォーカスが見えるか。
- ルール `a11y` の最低ラインも照合する。
